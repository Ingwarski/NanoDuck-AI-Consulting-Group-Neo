# Canonical terms

Working language: English. Product content and source metadata: English and Ukrainian only; role names and model IDs remain English. Russian and Belarusian language, terminology, sources and URLs are prohibited. Source keys: **PI** — [product idea](product-idea.md); **PRD** — [product requirements](prd.md); **MS** — [model preservation record](model-settings.md); **NF** — [Northflank deployment record](northflank-deployment.md); **AUTH** — repository-neutral combined-update authorization and source receipts.
